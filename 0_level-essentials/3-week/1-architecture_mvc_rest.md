# **Архитектура веб-приложений: MVC и REST API**

**Цель**: Понять разницу между MVC и API, научиться создавать endpoints.

## **MVC (Model-View-Controller)**

- **Модель (Model)**: Данные (например, класс `Product` с полями `Id`, `Name`).
- **Представление (View)**: HTML-страница, которая отображает данные.
- **Контроллер (Controller)**: Обрабатывает запросы, взаимодействует с моделью и возвращает представление.

**Но мы будем фокусироваться на REST API**, где вместо HTML возвращаются данные (JSON/XML).

---

## **REST API**

API (Application Programming Interface) — это набор правил, по которым клиенты (браузеры, мобильные приложения) общаются с сервером.  
REST — стиль архитектуры, где:

- Каждому ресурсу (например, пользователь, товар) соответствует URL.
- HTTP-методы (`GET`, `POST`, `PUT`, `DELETE`) определяют действие.

**Пример API для блога**:

- `GET /api/posts` → Получить все статьи.
- `POST /api/posts` → Создать новую статью.
- `GET /api/posts/5` → Получить статью с ID=5.
