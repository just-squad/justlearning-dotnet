# 📅 **План развития Todo List приложения (8 недель)**

## **Неделя 1: Консольное приложение (In-Memory)**

**Цель:** Освоить базовые конструкции C# и работу с коллекциями  
**Задачи:**

- Создать консольное приложение
- Реализовать базовые операции:
  - Добавление задачи
  - Просмотр списка задач
  - Отметка задачи как выполненной
  - Удаление задачи
- Хранение задач в `List<TodoItem>`
- Простая валидация ввода

**К концу недели:** Рабочее консольное приложение, которое хранит задачи в памяти.

## **Неделя 2: Работа с файлами (JSON/XML)**

**Цель:** Научиться сериализации и работе с файлами  
**Задачи:**

- Сохранять задачи в JSON/XML файл
- Загружать задачи при старте приложения
- Обрабатывать ошибки чтения/записи
- Добавить ID для задач (Guid/int)
- Реализовать поиск и фильтрацию (по статусу, названию)

**К концу недели:** Приложение сохраняет задачи между запусками.

## **Неделя 3: Переход на Web API (Minimal API)**

**Цель:** Освоить основы HTTP и Web API  
**Задачи:**

- Переписать приложение как Web API (ASP.NET Core Minimal API)
- Реализовать эндпоинты:
  - `GET /todos` – список задач
  - `POST /todos` – добавление
  - `PUT /todos/{id}` – обновление
  - `DELETE /todos/{id}` – удаление
- Использовать `List<TodoItem>` как хранилище
- Добавить Swagger/OpenAPI документацию

**К концу недели:** Простое API, которое можно тестировать через Postman/Swagger.
