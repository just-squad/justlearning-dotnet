# **Советы**

1. **Всегда используйте `Include`** для загрузки связанных данных, иначе получите `null` в навигационных свойствах.
2. **Логируйте SQL-запросы** для отладки (в `AppDbContext`):

   ```csharp
   options.UseLoggerFactory(LoggerFactory.Create(builder => builder.AddConsole()));
   ```

3. **Не забывайте про индексы** для ускорения поиска (добавляются через миграции).

---

## **Частые ошибки**

1. **Отсутствие миграций**: Если изменили модель, выполните `dotnet ef migrations add <name>`.
2. **N+1 проблема**: Получение данных в цикле (решается через `Include`).
3. **Строка подключения**: Убедитесь, что логин/пароль и хост указаны верно.
