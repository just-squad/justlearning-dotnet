# Программа обучения для специалистов с уровня Junior до уровня Middle Web Backend Developer на C\#

**Цель**: Научить проектировать высоконагруженные системы, работать с облачными сервисами, оптимизировать производительность и принимать архитектурные решения.

---

## **Недели 1-2: Продвинутые паттерны проектирования**

### **Темы недели 1-2**

1. **Архитектурные стили**:
   - Clean Architecture, Vertical Slice Architecture.
   - DDD (Domain-Driven Design): Агрегаты, Value Objects, Bounded Contexts.
   - CQRS + Event Sourcing: Реализация с использованием MediatR, Marten.
2. **Паттерны**:
   - Фабрики, Стратегии, Цепочки обязанностей.
   - Circuit Breaker, Retry, Bulkhead (Polly).
3. **Оптимизация SOLID**:
   - Когда нарушать SOLID осознанно (прагматичный подход).
   - Антипаттерны: God Class, Premature Optimization.

### **Практика недели 1-2**

- Перепроектирование монолита из финального проекта Junior в Clean Architecture.
- Реализация CQRS для модуля заказов (отдельные модели для чтения/записи).

---

## **Недели 3-4: Микросервисы и распределенные системы**

### **Темы недели 3-4**

1. **Основы микросервисов**:
   - Service Discovery (Consul), API Gateway (Ocelot/YARP).
   - Межсервисная коммуникация: gRPC, REST, GraphQL.
2. **Оркестрация и шины сообщений**:
   - RabbitMQ, Kafka: Pub/Sub, Event-Driven Architecture.
   - Реализация Saga-паттерна для распределенных транзакций.
3. **Документирование**:
   - OpenAPI (Swagger) для микросервисов.
   - AsyncAPI для событийных систем.

### **Практика недели 3-4**

- Разделение финального проекта Junior на 3 микросервиса (Пользователи, Задачи, Уведомления).
- Реализация обмена событиями через RabbitMQ (например, уведомление о новой задаче).

---

## **Недели 5-6: Производительность и оптимизация**

### **Темы недели 5-6**

1. **Профилирование**:
   - Использование dotTrace, Benchmark.NET.
   - Оптимизация запросов EF Core: N+1, выборка только нужных полей.
2. **Кэширование**:
   - Распределенный кэш (Redis, NCache).
   - Cache-Aside, Write-Behind, Read-Through.
3. **Продвинутый .NET**:
   - Memory Management, Span\<T\>, ArrayPool.
   - Параллелизм (Parallel.ForEach, Channels).

### **Практика недели 5-6**

- Оптимизация медленного API (с 2000 мс до 50 мс).
- Реализация кэширования GraphQL-запросов с помощью Redis.

---

## **Недели 7-8: Безопасность и DevOps продвинутого уровня**

### **Темы недели 7-8**

1. **Безопасность**:
   - OAuth 2.0 / OpenID Connect (IdentityServer6).
   - Защита от XSS, CSRF, DoS-атак.
   - Пентесты: OWASP Top 10, инструменты (Burp Suite).
2. **Infrastructure as Code**:
   - Terraform для облачной инфраструктуры (AWS/Azure).
   - Настройка Kubernetes: Pods, Deployments, Services.
3. **CI/CD**:
   - Мультистейдж-пайплайны (сборка, тесты, деплой в prod).
   - A/B-тестирование с помощью Feature Flags (LaunchDarkly).

### **Практика недели 7-8**

- Настройка кластера Kubernetes для микросервисов.
- Реализация автоматического отката деплоя при ошибках.

---

## **Недели 9-10: Облачные технологии (Azure/AWS)**

### **Темы недели 9-10**

1. **Сервисы облака**:
   - Azure: App Service, Functions, Cosmos DB, Service Bus.
   - AWS: Lambda, S3, DynamoDB, SQS.
2. **Бессерверная архитектура**:
   - Реализация Serverless API (Azure Functions + Durable Entities).
3. **Масштабирование**:
   - Auto-scaling, Load Balancers, CDN.
   - Реализация Rate Limiting (Azure API Management).

### **Практика недели 9-10**

- Перенос одного микросервиса в AWS/Azure.
- Настройка бессерверной обработки файлов (загрузка в S3 → триггер Lambda).

---

## **Недели 11-12: Системное проектирование и Soft Skills**

### **Темы недели 11-12**

1. **Системное проектирование**:
   - CAP-теорема, PACELC.
   - Проектирование Twitter-like системы или Uber.
2. **Работа в команде**:
   - Проведение код-ревью по принципам «Boy Scout Rule».
   - Работа с легаси-кодом.
3. **Карьера**:
   - Подготовка к собеседованиям (системный дизайн, алгоритмы).
   - Управление временем (GTD, Pomodoro).

### **Практика недели 11-12**

- Полноценный pet-проект: облачный SaaS-сервис с микросервисами, CI/CD, мониторингом.
- Mock-собеседование с разбором кейсов (например, оптимизация БД на 1 млн RPS).

---

## **Итоговые навыки Middle Developer**

1. **Архитектура**: Способен выбрать между микросервисами и монолитом, обосновать решение.
2. **Производительность**: Оптимизирует код и запросы на уровне памяти и CPU.
3. **Безопасность**: Реализует сложные сценарии аутентификации и защиты.
4. **DevOps**: Автоматизирует инфраструктуру, работает с K8s и облаками.
5. **Менталитет**: Видит систему целиком, а не только свой модуль.
