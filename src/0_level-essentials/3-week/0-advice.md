# **Советы**

1. **Используйте Postman** для тестирования API:
   - Отправляйте `GET`, `POST`-запросы.
   - Проверяйте статус-коды и тело ответов.
2. **Пишите чистые URL**:  
   `/api/posts` вместо `/getAllPosts`.
3. **Документируйте API** с помощью Swagger (он уже включен в шаблон `webapi` — зайдите на `/swagger` после запуска).

---

## **Частые ошибки**

1. **Забыть `[ApiController]`**: Без него не работает автоматическая валидация.
2. **Не использовать DI**: Создание зависимостей через `new` внутри контроллера усложняет тестирование.
3. **Игнорировать статус-коды**: Возвращайте `404`, если ресурс не найден, а не `200` с пустым телом.
