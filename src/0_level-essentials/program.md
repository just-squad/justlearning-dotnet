# Программа обучения для специалистов с нуля до уровня Junior Web Backend Developer на C\#

---

## Цель программы

Подготовить разработчиков, способных самостоятельно создавать и поддерживать backend-части веб-приложений на C# (ASP.NET Core), работать с базами данных, писать тесты, использовать инструменты DevOps и решать типовые бизнес-задачи.

---

## Структура программы

- **Формат**: Ежедневные занятия (теория + практика), мини-проекты в конце каждой недели, финальный проект.
- **Продолжительность**: 8 недель (40–50 часов в неделю).
